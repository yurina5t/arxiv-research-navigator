# Инструкция по разметке эталона (gold set)

Эталон нужен, чтобы измерить точность значений в таблице сравнения и проверить, что цитаты указывают на правильные места.
Статьи для эталона (не менее 30) отбираются из dev-корпуса скриптом с фиксированным seed, только с HTML-версией. Отбор и разметка — к чекпоинту 2.

## Поля

Поля совпадают с колонками таблицы сравнения из постановки задачи.

| Поле | Что писать | Пример |
|---|---|---|
| `method` | название метода + суть в одну фразу | SELF-RAG: LM учится решать, когда искать, и критикует свои ответы спецтокенами |
| `datasets` | датасеты экспериментов, через `;`, официальные названия | PopQA; TriviaQA; PubHealth; ASQA |
| `metrics` | метрики, через `;` | accuracy; FactScore; citation precision |

Для **каждого** поля — колонка `<поле>_anchor`: id абзаца/таблицы, откуда взято значение
(из URL `arxiv.org/html/<id>#S5.T2` → `S5.T2`). Если значения в статье нет — пишем `N/A`, якорь пустой.

## Правила
- Берём только то, что написано в статье, не домысливаем.
- Датасеты — только те, на которых **авторы проводят эксперименты**, не упомянутые в related work.
- Метрики — как в таблицах результатов; сокращения раскрываем, если они неоднозначны.
- Если сомневаемся — пишем в `comment`.
- Время: ~5–7 мин на статью.
